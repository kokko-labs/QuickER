# ER 図の編集

*[English](er-editor.md) | 日本語*

QuickER のメイン画面は 3 ペイン構成です。左が「ツールボックス」（エンティティ・リレーションの作成）、中央がキャンバス、右が「プロパティ」パネル（選択中の要素の編集）で、中央と右の境界はドラッグで広さを変えられます。要素の編集はダイアログではなく、選択して右のプロパティパネルで直接行う方式です。

## エンティティ

### 作成と削除

ツールボックスの「エンティティ追加」で、新しいテーブルがキャンバスへ追加されます（PK 列 `ID` 付きの `NewTable` として作成され、選択状態になります）。削除は「エンティティ削除」ボタンか Delete キーで行います。複数選択中は一括削除になり、接続されたリレーションも一緒に削除されます。

エンティティはドラッグで移動できます。Ctrl+C / Ctrl+V のコピー・貼り付け、Ctrl+D（ツールバー「複製」）の複製にも対応しています。

### プロパティの編集

エンティティを選択すると、プロパティパネルで次を編集できます。

| 項目 | 内容 |
|---|---|
| テーブル名 | テーブルの物理名 |
| 説明 | テーブルの説明。SQL Server では拡張プロパティ（MS_Description）と同期します |
| タイトル背景 | カードのタイトル色（ブルー / グリーン / イエロー / パープル / ピンク / グレー） |
| 項目 | 列の一覧（次節） |
| メモ | データベースにも生成コードにも出さない自由記入欄。Excel / HTML 定義書には出力され、Excel 定義書の再取込で復元されます |

### 列の編集

列はプロパティパネルの「項目」グリッドでインライン編集します。

- **追加 / 削除** — グリッド右上の「＋」で列を追加（現在の対象 DB の既定型で作成）、「−」または行末の削除ボタンで削除します
- **編集項目** — PK / FK / NULL のチェック、カラム名、型（対象 DB の型一覧から選択・自由入力も可）、説明
- **並び替え** — 行をドラッグして並び順を変更します
- **コピー / 貼り付け** — グリッド上で Ctrl+C / Ctrl+V が列単位で機能します

複合主キーは、複数の列に PK チェックを付けることで表現します。

### 一意制約

プロパティパネルの項目グリッドの下に、テーブルごとの「一意制約」カードがあります。カード本体は開閉でき、選択したテーブルに制約があるとき（および制約を追加したとき）は自動で開き、無いときは畳まれた状態になります（ヘッダーのトグルで手動開閉も可能）。「+」で制約を追加し、構成する列を 1 行ずつ足していきます。制約の中の「+」で空の行が増え、その行のドロップダウンから列を選ぶと確定します（1 列ならその列が一意、複数列ならその組み合わせが一意。行の並びが宣言順です）。ドロップダウンには同じ制約の他の行が使っていない列だけが並ぶため、同じ列を二重に選ぶことはできません。行を外すには「×」を押します。名前を空のままにすると DDL 生成時に `UQ_{テーブル}_{列…}` が合成されます（未入力の間は、その合成名が制約名欄のプレースホルダーとして表示されます）。DB から取り込んだ名前はそのまま保持されます。列を削除すると、その列を含む制約は列と一緒に削除されます（残りの列だけの制約へ黙って変質させないため）。いずれの操作も Undo できます。

キャンバス上では、制約の構成列のキー欄に `UQ` が表示されます。1 つの列が主キー・外部キー・一意制約の構成列を兼ねることがあるため、標識は `PK` > `FK` > `UQ` の優先度で 1 つに畳んで表示します。

## リレーション

### 作成

ツールボックスの「1 対 1」「1 対 多」「多 対 多」を押すと作成モードに入り、2 つのエンティティを順にクリックすると確定します。同じエンティティを 2 回クリックすると自己参照リレーションになります。作成時には**起点の主キー列すべて**について、列名から終点側の対応列を引き当ててペア化し、制約名は `FK_<終点>_<起点>` 形式で自動生成されます。引き当てられなかった起点列はペアに含まれないので（プロパティパネルで補えます）、同じ終点列が 2 度使われることもありません。

起点と終点が一致する既存のリレーションがある場合は重複として弾かれるので、既存のリレーションを選択して編集してください。重複とみなされるのは向きまで一致する場合だけなので、A → B があっても B → A は作成できます。

### プロパティの編集

リレーションを選択すると、プロパティパネルで次を編集できます。

| 項目 | 内容 |
|---|---|
| 種別 | 1 対 1 / 1 対 多 / 多 対 多（後から変更可能） |
| 制約名 | FK 制約名 |
| キー列の対応 | 列ペアの行。1 行が「起点（参照される側）の参照先列＝主キー列と一意制約の構成列が候補」と「終点（FK を持つ側）の外部キー列」の対で、＋で行を追加・×で削除し、両側を選ぶと確定します。2 行以上なら複合外部キーで、行の並びがそのまま構成列の順序になります |
| ON DELETE / ON UPDATE | 参照アクション: NoAction / Cascade / SetNull / SetDefault |

補足が 2 点あります。

- **多対多は中間テーブルを自動生成しません。** 多対多の線は「中間テーブルを介する設計」を概念として表すもので、FK 列と参照アクションの指定は無効になります。物理設計に落とす場合は、中間テーブルを自分で追加して 1 対多 2 本で表現してください
- **リレーションは列ペアの順序付きリストを保持します。** 複数列で構成される外部キー（複合外部キー）もそのまま表現され、取込・DDL 生成・スキーマ同期を通じて構成列が保たれます。ただし C# コード生成（ナビゲーションプロパティ・EF Core）が対象とするのは単一列の外部キーのみで、複合外部キーは警告つきでスキップされます

## 表示とナビゲーション

- **ズーム** — ステータスバーの「−」「＋」、倍率表示のクリックで 100%、「⛶」で全体表示。Ctrl+- / Ctrl++ / Ctrl+0 / Ctrl+Shift+0 のショートカットも使えます
- **ミニマップ** — ステータスバーのトグルで有効化。図がビューポートに収まらないときに右下へ表示され、クリック / ドラッグで視点を移動できます
- **検索** — Ctrl+F でテーブル名・カラム名の部分一致検索（大文字小文字は無視）。Enter で次の一致へ移動、候補のクリックでジャンプ、Esc で閉じます
- **関連ハイライト** — エンティティやリレーションを選択すると、接続された要素が強調され、無関係な要素は減光します
- **表示トグル** — ツールバーの「簡易表示」（PK / FK 以外の列行を折りたたみ）、「説明表示」、「NULL表示」。3 つの状態は次回起動時に復元されます
- **自動整列** — ツールバーの「整列(格子)」「整列(木)」「整列(自由)」（力学モデルで配置し、リレーション線が水平・垂直に近づくよう整列する）と、「幅自動」（カラム名と型が重ならない幅に調整）

## 複数選択と一括操作

Ctrl+クリックで選択のトグル、キャンバスのドラッグでラバーバンド選択（矩形に交差した要素を選択）、Ctrl+A で全エンティティ選択（リレーションの選択は解除されます）、Esc でエンティティの選択解除です（リレーションの選択と、作成途中のリレーション作成モードは保持されます）。2 個以上選択すると、プロパティパネルが一括操作カードに切り替わります。

- タイトル背景色の一括変更
- 選択中すべての削除
- ドラッグによるグループ移動

いずれも 1 回の Undo で戻せます。

## Undo / Redo

Ctrl+Z / Ctrl+Y（ツールバーの「元に戻す」「やり直す」）で戻せるのは、図の内容に対する個別の編集操作（エンティティと列とリレーションの追加・削除・変更、移動、複製、色変更、対象 DB の切替）です。AI チャットによる個別の編集も同じ履歴に乗ります。ただし、図を丸ごと入れ替える操作（ファイル取込・DB 取込・AI による図全体の生成）は履歴をクリアするため、Undo では戻せません。

選択状態、ズームやパン、ミニマップ表示といった「見え方」だけの操作は履歴に乗りません。

## 対象 DB の切替

ツールバー右の「対象DB:」コンボで、図のターゲット DBMS をいつでも切り替えられます。既存の列型は新しい方言の型へ自動変換され、変換できなかった列は警告ダイアログに一覧表示されます（元の型を保持）。切替は Undo で戻せます。詳細は [データベース連携](database.ja.md) を参照してください。

## ファイル操作と自動保存

新規（Ctrl+N）、開く（Ctrl+O）、保存（Ctrl+S）。保存形式は JSON 1 ファイルで、意味モデル（テーブル定義）と表示情報（座標・色）を分離して持つため、git での差分レビューに向きます。

ウィンドウを正常に閉じた場合は作業中の図が自動保存され、次回起動時に復元されます。強制終了や書込失敗はこの限りではないため、区切りごとに明示的に保存しておくことをおすすめします。

開いている図のファイルが外部（MCP サーバや別プログラム）で書き換えられると、GUI がそれを検知して追従します。未保存の変更がなければ自動で再読込し（ズーム・スクロール位置は維持）、ステータスバーに控えめな通知を出します。未保存の変更があるときだけ、再読込するか（変更を破棄）このまま続けるかを確認します。

## キーボードショートカット

| キー | 動作 |
|---|---|
| Ctrl+N / Ctrl+O / Ctrl+S | 新規 / 開く / 保存 |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直す |
| Ctrl+C / Ctrl+V | エンティティのコピー / 貼り付け（列グリッド上では列のコピー / 貼り付け） |
| Ctrl+D | エンティティの複製 |
| Ctrl+A | 全エンティティ選択 |
| Delete | 選択要素の削除 |
| Esc | エンティティの選択解除 / 検索を閉じる |
| Ctrl+F | 検索 |
| Ctrl+P | 印刷 |
| Ctrl+0 / Ctrl+Shift+0 | ズーム 100% / 全体表示 |
| Ctrl++ / Ctrl+- | ズームイン / ズームアウト |

テキストボックスにフォーカスがある間は、各コントロールの標準動作が優先されます。
