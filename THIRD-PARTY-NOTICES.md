# Third-Party Notices

QuickER's binary distributions include software from third parties. This file provides the attributions and license texts those components require.

Compiled from the dependency set as of 2026-08-02. Package versions are deliberately omitted: this file is revised when a component's **license** changes, not on every version bump. For the exact versions in a given build, see the `.deps.json` file shipped alongside the executable.

For QuickER's own license, see [LICENSE](LICENSE), [LICENSE-NC.md](LICENSE-NC.md), and [LICENSING.md](LICENSING.md).

## Scope

| Distribution | Third-party code included |
| --- | --- |
| GUI (`Setup.exe` / Portable zip) | Yes — the components marked *GUI* below are bundled |
| CLI (.NET tool package `QuickER.Cli`, command `quicker`) | Yes — the components marked *CLI* below are bundled |
| Runtime NuGet packages (`QuickER.Runtime`, `.SqlServer`, `.Sqlite`, `.EntityFrameworkCore`, `.InMemory`) | No — these packages contain only QuickER code; their dependencies are resolved by NuGet in the consuming project and carry their own notices |
| Code generated by QuickER | No |

Components are marked *GUI*, *CLI*, or *GUI, CLI* to indicate which distributions bundle them.

### WebView2 Runtime

QuickER uses the WebView2 SDK to host web content, but does **not** bundle or install the Microsoft Edge WebView2 Runtime. The Evergreen Runtime is a Microsoft component installed on and serviced through the user's machine, governed by Microsoft's own terms (https://developer.microsoft.com/microsoft-edge/webview2/). If it is not present, the features that need it are unavailable.
