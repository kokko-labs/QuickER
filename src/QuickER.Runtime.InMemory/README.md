# QuickER.Runtime.InMemory

The in-memory engine for the QuickER Repository, part of the runtime for C# code generated by [QuickER](https://github.com/kokko-labs/QuickER), an ER diagram designer for .NET. It implements the dialect-neutral contracts of `QuickER.Runtime` without touching a database, so your tests can run against the same Repository contract as production. Targets .NET 10 and depends only on `QuickER.Runtime`.

## When you need it

By default, QuickER inlines the runtime into the generated code, making the output self-contained. **This package is not required** in that mode.

When you generate code with `--use-runtime-packages`, QuickER leaves the runtime out of the output and your project references the runtime packages instead. Reference this one alongside `QuickER.Runtime` when the output includes the in-memory Repository (`--generate-in-memory-repositories`):

```sh
# Use the same version as the QuickER tool that generated your code
dotnet add package QuickER.Runtime.InMemory
```

The generated code header and the QuickER CLI output show the packages and versions each generated output needs.

> **Version compatibility:** QuickER.Runtime.InMemory versions match the QuickER tool version exactly. Reference the same version as the tool that generated your code.
