# QuickER.Runtime.Sync

The bidirectional sync engine for C# code generated by [QuickER](https://github.com/kokko-labs/QuickER), an ER diagram designer for .NET. It keeps a local SQLite database in step with a SQL Server one, with the server as the source of truth, and works entirely through the dialect-neutral contracts of `QuickER.Runtime`. Targets .NET 10 and depends only on `QuickER.Runtime`.

## When you need it

By default, QuickER inlines the runtime into the generated code, making the output self-contained. **This package is not required** in that mode.

When you generate code with `--use-runtime-packages`, QuickER leaves the runtime out of the output and your project references the runtime packages instead. Reference this one alongside `QuickER.Runtime`, `QuickER.Runtime.SqlServer`, and `QuickER.Runtime.Sqlite` when the output includes the sync support (`--generate-sync-support`):

```sh
dotnet add package QuickER.Runtime.Sync
```

The generated code header and the QuickER CLI output show the packages and versions each generated output needs.

> **Version compatibility:** QuickER.Runtime.Sync versions match the QuickER tool version exactly. Reference the same version as the tool that generated your code.
