# QuickER.Runtime

The runtime library for C# code generated by [QuickER](https://github.com/kokko-labs/QuickER), an ER diagram designer for .NET. It provides the dialect-neutral Repository contracts (`IRepository<TEntity, TKey>`, `ISqlExecutor`), the query infrastructure they rely on, and the HTTP client used by the generated three-tier configuration. Targets .NET 10 and has no NuGet package dependencies.

## When you need it

By default, QuickER inlines the runtime into the generated code, making the output self-contained. **This package is not required** in that mode.

When you generate code with `--use-runtime-packages`, QuickER leaves the runtime out of the output and your project references this package instead:

```sh
# Use the same version as the QuickER tool that generated your code
dotnet add package QuickER.Runtime
```

The generated code header and the QuickER CLI output show the packages and versions each generated output needs.

> **Version compatibility:** QuickER.Runtime versions match the QuickER tool version exactly. Reference the same version as the tool that generated your code.
